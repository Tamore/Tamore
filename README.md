I'm a full-stack developer who likes the unglamorous half of the job — the part where you
work out *why* the system behaves the way it does, not just make the screen look right.

- 🔭 Building **SkillMesh** and **CiteX** right now
- 🧠 Happiest in backend architecture, data pipelines, and wiring AI into products that actually use it
- 🧰 Fluent in **TypeScript**, comfortable in **Python** and **Kotlin**
